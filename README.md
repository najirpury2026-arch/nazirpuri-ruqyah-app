# নাজিরপুরী রুকইয়া ও দাওয়াখানা Android App

A simple Android WebView app that opens the website:

https://nazirpuriruqyah.blogspot.com/

## Build APK
1. Open the repository's **Actions** tab.
2. Select **Build Android APK**.
3. Press **Run workflow** (or wait for the push-triggered build).
4. Open the completed workflow run and download the **Nazirpuri-Ruqyah-debug-apk** artifact.

This is an initial website-wrapper app. It requires an internet connection to load the website.
